# exercicio 5 lista de revisao

a) Em um bloco de repetição 'while', a condição é checada antes de executar o bloco, onde num bloco 'do-while', a condição é checada após executar o bloco uma primeira vez, independente da condição a ser verificada.
b) Quando existe um número pré estabelecido de vezes a ser executado o loop. Exemplos são: percorrer uma lista, contagens regressivas, construção de listas filas ou pilhas com elementos conhecidos etc.
c) É um erro de lógica. Sintaticamente, não há erros já que o ';' representa o final de uma frase. Entretanto, caso a condição seja verdadeira, por o loop estar vazio, o programa ficará preso checando a condição infinitamente. Se for falsa, o programa passará direto.
