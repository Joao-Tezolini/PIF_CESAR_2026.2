Instrução                   Status (c/i)            Justificativa

a) int a;                   [ Correto ]             [ Declaração correta de uma variável do tipo inteiro ]
b) float b;                 [ Correto ]             [ Declaração correta de uma variável do tipo flutuante de precisão simples ]
c) double float c;          [ Incorreto ]           [ float e double são tipos base mutuamente exclusivos, não podem ser combinados entre si ]
d) unsigned char d;         [ Correto ]             [ Declaração correta de uma variável do tipo char para representar valores de 0 a 255 ]
e) unsigned e;              [ Correto ]             [ Declaração válida. Omitir o tipo base automaticamente assume o tipo "int" ]
f) long float f;            [ Incorreto ]           [ A modificador long se aplica apenas aos tipos base "int" e double" ]
g) long g;                  [ Correto ]             [ Declaração válida. Omitir o tipo base automaticamente assume o tipo "int" ]
h) long double h;           [ Correto ]             [ Declaração correta de uma variável do tipo flutuante de precisão estendida ]
